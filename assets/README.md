# Bundled assets

All files in this directory are maintained as part of JelloPoint Restaurant
Menu and are licensed GPL-2.0-or-later; see `../LICENSE.md`.

- `admin/` contains first-party administration CSS and JavaScript.
- `css/` contains first-party frontend and print styles.
- `icons/defaults/` contains first-party SVG icons supplied with the plugin.

No webfonts, tracking scripts, CDN resources or third-party runtime libraries
are bundled. Font-family declarations use locally available system fonts and
do not download font files.
